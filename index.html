BLE DEVICE SCANNER

Détectez les appareils Flipper Zero et lunettes Meta (Ray-Ban / Oakley) à proximité via Bluetooth Low Energy.
Chrome uniquement — Web Bluetooth API.

warning Ce navigateur ne supporte pas le Web Bluetooth. Utilisez Google Chrome.
phone_iphone iPhone détecté

Le scan Bluetooth Web ne fonctionne pas sur iPhone avec ce navigateur. Ouvrez cette page dans l'app Bluefy, puis lancez le scan depuis Bluefy.

1 Installez ou ouvrez Bluefy sur votre iPhone
2 Rouvrez cette page dans Bluefy
3 Lancez ensuite le scan Bluetooth depuis Bluefy
flag Activation requise

Le scan passif BLE nécessite d'activer un flag expérimental dans Chrome. Copiez l'URL ci-dessous, collez-la dans la barre d'adresse, activez le flag et relancez Chrome.

chrome://flags/#enable-experimental-web-platform-features
1 Collez l'URL dans la barre d'adresse de Chrome
2 Passez le flag sur Enabled
3 Cliquez Relaunch pour redémarrer Chrome

Comment ça fonctionne ?

bluetooth 01

Web Bluetooth API

Chrome permet aux pages web d'interagir avec les appareils BLE via l'API Web Bluetooth, directement depuis le navigateur.

fingerprint 02

Identification MAC

Chaque Flipper Zero possède une adresse MAC BLE débutant par 80:E1:26, un préfixe unique à Flipper Devices Inc.

security 03

Scan Passif

Le scan est purement passif — aucune connexion n'est établie avec l'appareil détecté. Seule l'annonce BLE est analysée.

Si un composant est OFFLINE, le scan ne pourra pas détecter les appareils.

Désactiver le flag Chrome

Quand vous avez fini le scan passif, vous pouvez remettre Chrome dans son état normal en revenant sur le même flag expérimental.

1 Ouvrez chrome://flags/#enable-experimental-web-platform-features
2 Repassez l'option sur Default ou Disabled
3 Cliquez sur Relaunch pour redémarrer Chrome
